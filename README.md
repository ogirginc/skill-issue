# skill-issue

My personal [Agent Skills](https://agentskills.io) for coding harnesses. Opinionated and tuned to how I work, so fork freely.

## Skills

| Skill | What it does |
|---|---|
| [`code-comments`](.agents/skills/code-comments/SKILL.md) | Write comments that explain *why*, never restate *what*. Any language. |
| [`interview`](.agents/skills/interview/SKILL.md) | Grill me about a plan, then write the decisions up as a spec next to it. |
| [`rails/schema-healer`](.agents/skills/rails/schema-healer/SKILL.md) | Clean `schema.rb` / `structure.sql` of ghost changes from abandoned branches' migrations. |
| [`rails/vanilla`](.agents/skills/rails/vanilla/SKILL.md) | 37signals-style vanilla Rails: rich models, RESTful controllers, Hotwire, fixtures. Based on [Fizzy](https://github.com/basecamp/fizzy) and its [style guide](https://github.com/basecamp/fizzy/blob/main/STYLE.md). |
